# Daraz Front-End Web Clone

A responsive, pixel-perfect front-end recreation of the Daraz e-commerce platform homepage, focusing on modern web layout techniques, responsive visual sections, and clean structural HTML.

## 🚀 Built With
* **HTML5:** Semantic layout structure
* **CSS3:** Flexbox, CSS Grid, custom positioning, and responsive design

## ✨ Key Features
* Custom-built Impact & Stats metrics section
* Custom multi-slide layout and interactive gallery structure
* Clean UI component layout matching the live Daraz interface
